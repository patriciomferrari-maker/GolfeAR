# GolfeAR ⛳

Aplicación web integral para seguimiento, estadísticas y análisis de salidas de golf, juego en tiempo real (multijugador) y duelos directos entre amigos.

## 🌟 Características

* **Registro de Salidas:** Registro detallado hoyo a hoyo de golpes, putts, multas, FIR (Fairways in Regulation) y tiempos por hoyo.
* **Juego en Vivo Multijugador:** Lobbies compartidos en tiempo real vía Supabase para jugar con amigos y ver scores actualizados hoyo a hoyo.
* **Duelos vs Amigos:** Historial de enfrentamientos directos, mano a mano hoyo por hoyo, comparativa de tarjetas y estadísticas históricas.
* **Dashboard y Estadísticas Avanzadas:** Evolución de hándicap / diferencial de score, análisis por par (Par 3, Par 4, Par 5), distribución de scores y logros desbloqueables.
* **Canchas Oficiales y Personalizadas:** Soporte para canchas de 9 y 18 hoyos con ratings y slopes oficiales (San Isidro Labrador, Costa Esmeralda, etc.) y creador de canchas personalizadas.
* **Sincronización en la Nube:** Autenticación y persistencia automática en base de datos PostgreSQL mediante Supabase.

## 🚀 Tecnologías

* HTML5 / CSS3 moderno (interfaz responsiva adaptada a móviles)
* JavaScript Vanilla (SPA optimizada para carga ultra rápida y bajo consumo)
* Chart.js para gráficos analíticos
* Supabase (PostgreSQL + Auth + Realtime)
* Vercel (Hosting y despliegue continuo)
